# ScreenCutOcrCn

Windows 截图 + 中文 OCR 小工具，基于 [CnocrCpp](https://github.com/CoireLen/CnocrCpp)（PP-OCRv3 检测 + CTC 识别，onnxruntime 推理）。

## 快捷键

| 快捷键 | 功能 |
| --- | --- |
| `Alt + C` | 框选区域 → 识别文字 → 写入剪贴板 |
| `Alt + A` | 框选区域 → 截图写入剪贴板 |
| `Alt + V` | 竖向长截图（滚动拼接） |
| `Alt + H` | 横向长截图（Shift 滚动/横向滚动条拼接） |
| `Esc` / 右键 | 取消当前框选 |

快捷键可在主界面工具栏的“快捷键设置”或托盘菜单中修改：按下新组合键即**自动保存**并写入配置文件，无需点保存；**在按键框上点右键**可直接清空该项（留空表示禁用）。非法组合（缺少 Ctrl/Alt/Win、与其他项重复）会提示原因并回退到上一次的有效值。录制期间旧热键临时注销，避免边改边触发；关闭对话框后按新配置重新注册。

选区界面：半透明暗化遮罩、十字准线、实时显示选区尺寸、四角把手，顶部提示操作方式。识别完成后屏幕上方会短暂提示结果行数。

## 长截图

1. 按 `Alt + V`（竖向）或 `Alt + H`（横向）框选要截取的区域；
2. 框选完成后出现置顶控制条，显示“已拼接：N px · M 帧”；
3. 在选区内滚动页面：竖向直接滚动鼠标滚轮；横向需按住 `Shift` 滚动或拖动横向滚动条；
4. 程序每 320 ms 抓一次选区并按重叠区域自动拼接，也可以在识别到滚动距离过大时放慢速度；
5. 点击“完成”或按 `Enter` 结束（`Esc`/“取消”放弃），结果写入剪贴板并记入截图历史。

拼接按模板匹配找重叠：滚动太快、画面变化过大时提示“未匹配到重叠区域”，此时会跳过该帧；反向滚动会被忽略。单方向最大长度 20000 px，达到上限后提示点击“完成”。控制条使用 `WDA_EXCLUDEFROMCAPTURE` 排除在截图之外。

## 主界面与托盘

主界面是 Qt 窗口，顶部工具栏可直接触发截图、识别、竖向/横向长截图与快捷键设置，下方两个标签页：

| 标签页 | 内容 | 操作 |
| --- | --- | --- |
| 历史 | 左侧截图列表（缩略图 + 时间 + 尺寸 + 识别字数）；右侧上方图片预览，下方识别文字 | 双击或“复制图片”复制原图；“复制文字”复制识别结果；“文字识别”对所选截图重新 OCR；右键菜单同上；“清空历史”（确认后清空） |
| 日志 | 启动信息、截图/识别过程、耗时与错误 | “清空日志” |

- 截图与识别共用一条记录：自动识别（`Alt+C`）和手动“文字识别”都会把文字回填到对应截图条目，右侧下方即时显示；重复识别会覆盖为最新结果。
- 历史上限 30 条、日志 500 行，超出后自动丢弃最旧的记录。
- 尚未识别的记录，识别文字框显示提示占位；右键菜单中的“复制文字”在无文字时置灰。
- **关闭窗口**时弹窗三选一：`常驻托盘`（隐藏窗口，热键与托盘菜单继续可用）、`退出程序`、`取消`。
- **托盘菜单**（右键托盘图标）：`显示主界面`、`截图`、`识别`、`竖向长截图`、`横向长截图`、`快捷键设置...`、`退出`；单击或双击托盘图标恢复主界面。
- 托盘气泡、状态栏、菜单项文本都会显示当前快捷键。
- 快捷键保存在 `%APPDATA%/CoireLen/ScreenCutOcrCn.ini` 的 `[hotkeys]` 段，键名为 `shot`、`ocr`、`long_vertical`、`long_horizontal`。

## 环境依赖

| 依赖 | 说明 |
| --- | --- |
| onnxruntime | 1.31.1，默认路径 `E:/Lib/onnxruntime-win-x64-1.31.1`（需含 `include/`、`lib/`） |
| OpenCV | 通过 vcpkg 安装，默认 vcpkg 根目录 `E:/Lib/vcpkg` |
| Qt6 | 推荐同样用 vcpkg：`vcpkg install "qtbase[core,gui,widgets]:x64-windows"`；也可用官方 Qt SDK |
| CMake / MSVC | CMake ≥ 3.21，Visual Studio 2022+，C++17 |

路径均可在配置时覆盖：

```sh
cmake -S . -B build -G "Visual Studio 17 2022" -A x64 \
  -DONNXRUNTIME_ROOT=<onnxruntime解压目录> \
  -DVCPKG_ROOT_DIR=<vcpkg目录> \
  -DQT_ROOT=<官方Qt msvc目录，使用vcpkg时不用填>
cmake --build build --config Release
```

> 使用 Visual Studio 2026 内置 CMake 时，生成器改为 `-G "Visual Studio 18 2026" -A x64`。

构建后自动完成：

1. 复制 `onnxruntime.dll`、`onnxruntime_providers_shared.dll` 到输出目录；
2. 复制 `modle/*.onnx`、`dict/*.txt` 到输出目录（程序按相对路径读取）；
3. 用 `windeployqt` 部署 Qt 运行时与平台插件（没有时直接复制 Qt 插件目录）。

运行时请从输出目录启动 `ScreenCutOcrCn.exe`。

> Release 构建为 Windows 子系统，启动时不会弹出控制台窗口，运行日志显示在主界面“日志”页；Debug 构建保留控制台，便于查看 `std::cerr` 输出。

## 错误提示与健壮性

- **启动自检**：检查 `modle/cnocr136fc.onnx`、`modle/ch_PP-OCRv3_det_infer.onnx`、`dict/label_cn.txt`，缺失时弹窗列出**绝对路径**与当前工作目录，便于定位部署问题。
- **初始化失败**：OCR 引擎构造异常时弹窗显示异常信息、当前工作目录与排查建议（模型完整性、onnxruntime、VC++ 运行库），进程以返回码 1 退出。
- **热键被占用**：启动或保存快捷键时若注册失败，日志页会列出失败项并弹出提示条，程序继续运行；可在“快捷键设置”中换一个组合。
- **运行时错误**：截图失败、OCR 异常、剪贴板被占用等都会在屏幕顶部以提示条显示具体原因，而不是静默失败。
- **并发保护**：同一时刻只执行一个截图/识别流程，重复触发会提示“正在处理中，请稍候”。
- **剪贴板**：打开剪贴板失败时重试；文本按 UTF-8 解码为 UTF-16；图片以标准 `CF_DIB`（32 位、自底向上）写入并正确处理行尾填充，所有失败路径都会释放句柄/内存并输出错误码。
- **提示条**：全局单实例、纯文本渲染（OCR 内容中的 `<...>` 不会当成富文本）、自动换行并限制最大宽度。

## 常见问题

| 现象 | 排查方向 |
| --- | --- |
| 启动弹窗“缺少识别所需的模型/字典文件” | 按弹窗给出的绝对路径补齐 `modle/`、`dict/`，或从输出目录启动 |
| 启动弹窗“OCR 初始化失败” | 模型文件可能损坏；确认 `onnxruntime.dll` 与 VC++ 运行库（`vcruntime140*.dll`、`msvcp140*.dll`）在 exe 旁 |
| 启动无窗口 / 闪退 | 缺少 `Qt6Core.dll`、`Qt6Gui.dll`、`Qt6Widgets.dll` 或 `platforms/qwindows.dll`，重新执行 `windeployqt` |
| 弹窗“热键注册失败” / 提示“有 N 个快捷键注册失败” | 快捷键被其他程序占用（如输入法、截图工具），日志页会列出具体项，关闭冲突程序后重新设置或重启本程序 |
| 截图变黑 | 已内置 GDI 兜底；若仍出现，多为显卡驱动/远程桌面限制，可先切换桌面后重试 |

## 实现说明

- `screen_capture.*`：截图与选区。截图和 `QDialog` 遮罩都在 GUI 线程执行；`QScreen::grabWindow` 返回全黑时退回 GDI `BitBlt`（每次新建 DC/Bitmap），主屏物理区域由 Win32 监视器信息确定。提示条用 Win32 物理坐标居中，避免高 DPI 下 Qt 逻辑/物理坐标不一致导致偏移。`grab_primary_screen()` 供长截图连续取帧。
- `long_capture.*`：长截图。框选后每隔 320 ms 抓一次选区，取上一帧中部条带在新帧上做 `TM_CCOEFF_NORMED` 匹配得到滚动位移，按位移追加新行/列；选中区域尺寸变化时按比例缩放；片段收集完一次性 `vconcat`/`hconcat`，避免反复整图拷贝；控制在 GUI 线程用 `QEventLoop` + `QTimer` 驱动，控制条通过 `WDA_EXCLUDEFROMCAPTURE` 排除在截图之外。
- `hotkey_config.*` / `hotkey_service.*`：快捷键默认值、`QSettings` 持久化、`QKeySequence` → Win32 虚拟键映射与合法性校验（必须含 Ctrl/Alt/Win）；设置对话框在每次修改后立即校验并 `save_hotkeys()` 写盘，输入框右键由事件过滤器拦截后清空该项（`QKeySequenceEdit` 内部编辑框也一并安装过滤器）；`HotkeyService` 在配置变更时清空并重新注册，编辑对话框打开期间临时注销全部热键，关闭时统一按最新配置注册。
- `main.cpp`：热键线程只负责把任务排队回 GUI 线程；截图/长截图共用 `capture_and_select()`，OCR 放入 `QThreadPool` 异步执行，结果统一写剪贴板并弹出提示。
- `main_window.*`：主窗口与托盘。“历史”页把截图与识别合并成一条条记录（`Qt::UserRole` 存 `QImage`、`+1` 存识别文字、`+2` 存基础标题），右侧竖分隔条上方是图片预览、下方是只读文字框，预览底色跟随系统主题；列表右键用 `itemAt()` 定位后弹 `QMenu`（文字识别 / 复制图片 / 复制文字）。OCR 结果回到 GUI 线程后按 `QImage::cacheKey()` 找回原截图条目并回填文字（隐式共享，同一份像素即同一身份）；`closeEvent` 拦截关闭并提供“常驻托盘/退出程序/取消”；`QSystemTrayIcon` 菜单项与工具栏信号复用同一条流程，`setQuitOnLastWindowClosed(false)` 保证窗口隐藏后进程继续运行。
- `cnocr.*` / `cnstd.*` / `db_postprocess.*` / `modle.*` / `text_utils.*`：与 CnocrCpp 同步的检测、后处理、推理封装与 UTF-8 工具。
